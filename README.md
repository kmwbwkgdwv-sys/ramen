# 🍜 ラーメン屋シミュレーター

ラーメン屋を経営する、3Dの経営シミュレーションです。スープを炊いて、麺を茹でて、湯切りして、トッピングをのせて、お客さんに出します。
食券機の売上を泥棒から守り、厨房の火事を消し、ラーメン評論家をうならせて、お店を大きくしていきます。
お店の隣には **賭場（とば）** があって、丁半博打・チンチロリン・スロットで一発逆転もねらえます（負けることもあります）。
ブラウザだけで動くので、GitHub Pages に置くだけでスマホ（横画面）でも PC でも遊べます。**最大4人の協力プレイ** にも対応しています。

> 「Japanese Ramen Simulator」の遊び方（ラーメン作り・食券機・泥棒と手裏剣・火事と消火器・評論家・丁半博打）を参考にしたオリジナル作品です。公式作品・開発元とは関係ありません。
> お店のしくみ（ルーム・セーブ・ランキング・キャラメイク・建築モード）は「TCGカードショップシミュレーター」をもとにしています。

## 🍜 ラーメンの作り方（ぜんぶ一から）

### だしを炊く（朝の仕込み）
1. **水を入れる**：寸胴鍋を狙って「水を入れる」。
2. **材料を入れる**：鶏ガラ・豚骨・煮干しのどれか（1つで10杯分）と、香味野菜（ねぎ・しょうが・にんにく）や昆布を入れる。いちばん多く入れた材料のだしになります。
3. **火をつける**：鶏ガラ30秒・豚骨50秒・煮干し25秒で使えるようになり、長く炊くほどコクが出ます（煮干しは炊きすぎると苦い）。
4. **アクを取る**：炊きはじめに出てくるアク（灰色の泡）を長押しで取る。取らないとにごって品質が下がります。

### タレ（かえし）を作る
トッピング台で「タレを作る」→ 材料（醤油・塩・味噌・練りごまとラー油・たまり醤油）を出して **長押しで混ぜる** と、20〜30杯分のタレができます。

### 一杯を作る
1. **麺を茹でる**：茹で麺機に「麺を入れる」（先に入れておくと待たずにすむ）。
2. **丼を取る**：食器棚で「丼を取る」（丼は大きめの直径28cmくらい）。
3. **タレを入れる**：トッピング台で、注文に合うタレを丼に入れる。
4. **だしを注ぐ**：寸胴鍋で「スープを注ぐ」。**だし＋タレ** でスープの種類が決まります。
5. **湯切り**：丼を持って茹で麺機のてぼを狙い、**長押しで湯切り**（てぼを上げて振る）。水を切りきると麺が丼に入ります。**茹でた秒数** で麺の固さが決まります。湯切りせずに入れると水っぽくなって点数が下がります。

   | 固さ | 秒数 |
   |---|---|
   | かため | 15〜21秒 |
   | ふつう | 21〜27秒 |
   | やわらかめ | 27〜33秒 |
   | のびた（失敗） | 42秒〜 |

6. **トッピング**：トッピング台で好きなものをのせる（1杯に6種類まで）。注文票を選んでいれば「📋 注文どおり」でまとめてのせられます。
7. **出す**：注文したお客さんを狙って「出す」。カウンター席なら **厨房からカウンター越しに** 出せます。**受け渡し台** に置くと、接客のアルバイトが運びます。

**点数のつけ方**：注文どおりのスープ（だし＋タレ）・麺の固さ・湯切り・トッピングか、だしのコクとアク、出すまでの時間で決まります。

## 🎲 賭場（お店の隣）

お店を出て右の **賭場** に入ると遊べます。原作と同じように、**お店のレジを開けてお金をつかみ**（レジの中・金庫から好きな額）、賭場の台で **お金をセット** して勝負します。勝ったお金は手持ちになるので、レジに戻しましょう（1日の終わりには自動でレジに戻ります）。

| 遊び | 解放 | ルール |
|---|---|---|
| 🎲 丁半博打 | Lv.1 | 壺振りがサイコロ2つを振る。合計が偶数なら **丁**、奇数なら **半**。14秒の間に賭けて、当たると賭け金の2倍（寺銭5%を引く）。**ルームの全員が同じ勝負に乗れる**（丁と半に分かれてもOK） |
| 🥣 チンチロリン | Lv.8 | 胴元（親）とどんぶりにサイコロ3つを振って役で勝負。**ピンゾロ 5倍・ゾロ目 3倍・シゴロ 2倍**、ヒフミは負けで2倍払い。目なしは3回まで振り直し |
| 🎰 スロット | Lv.12 | 3つのリールをそろえる。7・7・7 で200倍、BAR 40倍、🍜 20倍、🍉 12倍、🔔 8倍、🍒 5倍（🍒2つでも2.5倍） |

> 胴元がもうかるようになっているので、続けるほど少しずつ負けます。ほどほどに。

## 👥 みんなで経営（最大4人）

- メニューの「👥 みんなで経営（ルーム）」→ **ルームを作る**（ホスト）か、**ルームIDを入れて参加**。
- ホストのお店に最大4人が集まって、同じ厨房で一緒に働けます（スープ係・麺係・洗い場…と分けると速い）。
- お店の計算（お客さん・アルバイト・泥棒・火事・賭場）はホストの端末で行い、参加者の操作はホストに送られます。
- お金・食材・設備はルームのお店のもの。賭場の丁半博打は全員で同じ勝負に乗れます。
- ホストが抜けるとルームは終わります（お店はホストのセーブに残ります）。

## 🚀 GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例：`ramen-shop-simulator`）を **Public** で作成。
2. このフォルダの中身（`index.html` / `css` / `js` / `icons` / `README.md` など）を **フォルダごと** アップロードして Commit。
   - `index.html` がリポジトリの一番上にある状態にしてください。
3. **Settings → Pages** で **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save。
4. 1〜2分後に `https://あなたのユーザー名.github.io/リポジトリ名/` で遊べます。

ビルド不要の素の JavaScript（ES モジュール）です。three.js と Firebase は CDN から読み込みます。
ローカルで試すときは `python3 -m http.server` などでフォルダを配信して `http://localhost:8000` を開いてください（ファイルを直接開くと動きません）。

## 🔥 Firebase の設定（オンライン機能）

`js/firebase-config.js` には、カードショップと同じ Firebase プロジェクト **card-shop-d54b1** を設定してあります。
データはデータベースの **`ramen/` の下** に保存されるので、カードショップ（`tcg/`）のデータとはまざりません。

### はじめにやること（Firebase コンソール）
1. **Authentication → Sign-in method → 匿名** が有効になっているか確認（カードショップで有効にしていればそのままでOK）。
2. **Realtime Database → ルール** に、ルールを貼り付けて **公開**。
   - カードショップと **同じプロジェクトで両方動かす** ときは **`database.rules.with-tcg.json`**（`tcg` と `ramen` の両方が入っています）を貼ってください。
   - ラーメン屋だけのプロジェクトなら `database.rules.json` でOKです。
   - ※ `database.rules.json` だけを貼ると、カードショップ（`tcg/`）のルールが消えて動かなくなります。
3. **Authentication → 設定 → 承認済みドメイン** に、公開するドメイン（`あなたのユーザー名.github.io`）を追加。

### 別のプロジェクトに変えるとき
**プロジェクトの設定 → マイアプリ → ウェブ** でアプリを登録し、表示される `firebaseConfig` の値（`apiKey`・`authDomain`・`databaseURL`・`projectId`）を `js/firebase-config.js` に書きかえて、上の1〜3をそのプロジェクトでも行ってください。

Firebase がつながらなくても「ひとりで経営」は遊べます（データは端末に保存）。

### データの置き場所
| 場所 | 内容 |
|---|---|
| `ramen/saves/<引き継ぎコード>` | セーブデータ（お店・キャラ） |
| `ramen/lb/<プレイヤーID>` | ランキング：`lv`（店レベル）・`c`（出したラーメン杯数）・`s`（総売上）・`p`（プレイ時間） |
| `ramen/rooms/<ルームID>` | ルーム（ホストのお店・お客さんの動き・チャット） |
| `ramen/shops/<ルームID>` | ルームのお店のバックアップ |

## 📁 ファイル構成

```
index.html              入口（three.js は CDN から読み込み）
css/style.css           画面デザイン
js/main.js              起動・画面遷移・メインループ
js/game.js              ゲーム中の操作（狙った設備と手に持った物で行動が変わる）
js/sim.js               経営シミュレーション（調理・お客さん・泥棒・火事・評論家・アルバイト・賭場・1日の流れ）
js/data.js              お店の形・スープ・トッピング・サイド・食材・設備・アルバイト・賭場・レベルのデータ
js/gameui.js            ゲーム中のUI（注文票・パソコン・メニュー作り・賭場・レベル・収支）
js/render.js            3D描画（鍋・てぼ・丼・料理・火と湯気・手裏剣・ドローン・「次」の矢印・商品の撮影）
js/thumbs.js            商品の絵（3Dモデルを撮影した画像）をパソコン・注文票・券売機に配る
js/nav.js               お客さん・アルバイトの道さがし
js/models/food.js       ラーメン（スープ・麺・トッピング）・サイド・食器の3Dモデル
js/models/products.js   仕入れる食材・器のパッケージの3Dモデル
js/models/fixtures.js   設備の3Dモデル（看板・装飾・賭場など）
js/models/equip.js      厨房機器・家具のくわしい3Dモデル（洗い場・コンロ・茹で麺機・冷蔵庫・棚・テーブルなど）
js/models/world.js      お店・賭場・町並みの3Dモデル
js/models/character.js  キャラクター（食べる・湯切り・座るなどの動き）
js/net.js               Firebase（引き継ぎ・ルーム・チャット・ランキング）
js/save.js              セーブデータ・引き継ぎコード
js/audio.js             BGMと効果音（Web Audio）
js/firebase-config.js   Firebase の設定
database.rules.json             Realtime Database のルール（ramen だけ）
database.rules.with-tcg.json    カードショップと同じプロジェクトで使うときのルール（tcg＋ramen）
```
